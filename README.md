# Task 4 – Sales Performance Dashboard (Power BI)

## Project Overview
This project was completed as part of **Task 4** of the internship program. The objective was to design an interactive Sales Performance Dashboard using Power BI to analyze business performance through data visualization and key performance indicators (KPIs).

## Objectives
- Analyze sales performance using Power BI.
- Monitor key business metrics.
- Compare sales and profit across different regions and categories.
- Create an interactive dashboard using slicers and charts.
- Support data-driven decision-making.

## Dataset
- **Dataset:** Sample Superstore Dataset
- **Format:** CSV
- **Records:** Sales transaction data including Orders, Sales, Profit, Region, Category, Segment, and Order Date.

## Tools Used
- Microsoft Power BI Desktop
- Microsoft PowerPoint
- GitHub

## Dashboard Features
- KPI Cards
  - Total Sales
  - Total Profit
  - Total Orders
- Sales by Category (Bar Chart)
- Profit by Region (Column Chart)
- Monthly Sales Trend (Line Chart)
- Sales by Segment (Pie Chart)
- Interactive Slicers
  - Region
  - Category
  - Segment
  - Year

## Key Insights
- Identified overall sales, profit, and total orders.
- Compared sales across product categories.
- Analyzed profit by region.
- Observed monthly sales trends.
- Used slicers to interactively filter and explore the data.
